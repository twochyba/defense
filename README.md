# Tower Defense Simulator (TDS): Оновлення «Військовий порт» ⚓🛳️

Стратегічна гра в жанрі **Tower Defense Simulator (TDS)** на HTML5, CSS3, Canvas API та Web Audio API. Основний код — у [index.html](index.html), графіка й рендерер порту — у папці [assets](assets/images/README.md). Для запуску та публікації копіюйте їх разом.

Порт використовує згенеровані спрайти десантного катера, есмінця, субмарини й авіаносця; текстури води та бетону; контейнери, склади, цистерни, радари, маяк і кран. Кораблі плавно повертаються за маршрутом, мають кільватерний слід, а радари й сигнальні вогні анімовані. Статична карта кешується, ресурси завантажуються один раз. Нові морські WebP-файли займають приблизно 126 КіБ.

Перевірка в Chrome або Edge без npm-залежностей: `node tests/naval-art.cjs`. Джерела та промпти: [assets/images/naval/README.md](assets/images/naval/README.md).

## 🎮 Керування

Перед вибором карти оберіть складність: «Звичайний», «Складний» або «Кошмар».
За замовчуванням вибрано «Складний». Вищі рівні посилюють ворогів і босів,
збільшують кількість звичайних ворогів, скорочують інтервали спавну, зменшують
стартову енергію, життя бази та енергетичні нагороди за ворогів і хвилі. Вибір зберігається під час перезапуску.
У «Кошмарі» авіанальоти починаються з другої хвилі та повторюються кожні дві хвилі.
Кнопка «Хвиля» запускає наступну хвилю лише після завершення поточного бою.
- `1` - `6` — вибір карток загону та електростанції в порядку їх розташування.
- `Enter` / `N` — почати наступну хвилю після завершення поточної.
- `U` / `S` — покращити / продати виділену вежу.
- `Пробіл` — старт хвилі / пауза.

## ⚡ Електростанція «Іскра»

Енергія оплачує всі будівлі, захист і покращення в бою. Монети та кристали в меню
залишаються валютою постійного відкриття юнітів. Енергетичні нагороди за ворогів,
хвилі й роботу заводу нараховуються автоматично; заряд «Іскри» потрібно збирати вручну.

«Іскра» завжди доступна окремо від п'яти слотів загону та коштує 100 ⚡.
Заряд виробляється лише під час активних хвиль. Натисніть станцію на полі або кнопку
«Забрати» в її панелі, щоб перенести заряд у доступну енергію. Повна батарея зупиняє
виробництво; на паузі воно теж зупиняється. Продаж повертає 70% вкладеної енергії та забирає накопичений цілий заряд.
