# Tower Defense Simulator (TDS): Оновлення «Військовий порт» ⚓🛳️

Стратегічна гра в жанрі **Tower Defense Simulator (TDS)** на HTML5, CSS3, Canvas API та Web Audio API. Основний код — у [index.html](index.html), графіка й рендерер порту — у папці [assets](assets/images/README.md). Для запуску та публікації копіюйте їх разом.

Порт використовує згенеровані спрайти десантного катера, есмінця, субмарини й авіаносця; текстури води та бетону; контейнери, склади, цистерни, радари, маяк і кран. Кораблі плавно повертаються за маршрутом, мають кільватерний слід, а радари й сигнальні вогні анімовані. Статична карта кешується, ресурси завантажуються один раз. Нові морські WebP-файли займають приблизно 126 КіБ.

Перевірка в Chrome або Edge без npm-залежностей: `node tests/naval-art.cjs`. Джерела та промпти: [assets/images/naval/README.md](assets/images/naval/README.md).

## ⚓ Нове оновлення: «Військовий порт»

### 1. 🗺️ Нова карта — «Військовий порт»
- **Локація:** Велика військово-морська база з доками, складами, вантажними контейнерами, паливними цистернами, радарами, маяком, буями та військовими кораблями на рейді.
- **Морський маршрут:** Вороги прибувають із відкритого моря зліва, проходять через доки, контейнерний термінал, внутрішні військові склади та наступають на командний центр бази праворуч.
- **Атмосфера:** Темні морські глибини, океанські хвилі та біла піна, виття бойової сирени тривоги, свист реактивних літаків та гуркіт вибухів.

### 4. 🚀 Особлива механіка: Ракетні удари та Авіанальоти
- **Ракетні солдати, Есмінці та Адмірал** вибирають вежі оборони та завдають по них прицільних ракетних ударів.
- Ракети мають яскраву траєкторію польоту, димовий слід і червоне попередження перед вибухом.
- **Морський дрон** виявляє підводні човни та знищує їх глибинними зарядами до того, як вони дістануться бази.

### 5. 👑 Фінальний бос — Авіаносець «Адмірал» (Хвиля 30)
- **Модель:** Гігантський флагманський корабель із палубою, злітно-посадковою смугою, обертовим радаром, бортовими баштами та реактивними палубними винищувачами.
- **HP:** 55 000+ HP із 30% бронею.
- **Бойові фази:**
  - **Фаза 1 (100% - 50% HP):** Регулярні запуски авіаударів винищувачів по карті + виклик підкріплень з броньованих солдатів.
  - **Фаза 2 (50% HP):** Форсаж двигунів! Частота авіанальотів збільшується на 40%, додаються додаткові літаки у ланці.
  - **Фаза 3 (20% HP):** Відчайдушний залп! Бос запускає одночасний залп 6 важких ракет по позиціях гравця.
  - **Перемога:** Масштабна серія феєрверків і вибухів по всьому кораблю + нагорода **«Військово-морська скриня Адмірала»** (+1500🪙 та звання Командувача Флоту).

## 🎮 Керування
- `1` - `6` — вибір базових веж (Стрілець, Гармата, Маг, Снайпер, Тесла, Отруйна).
- `7` - `9` — швидкий вибір морських веж (Берегова гармата, Ракетний катер, Морський дрон).
- `Enter` / `N` — кнопка **SKIP** (миттєвий пропуск хвилі з бонусом золота).
- `U` / `S` — покращити / продати виділену вежу.
- `Пробіл` — старт хвилі / пауза.
