# Tower Defense: Захисники Королівства 🏰⚔️

Повноцінна стратегічна гра в жанрі **Tower Defense (TDS)**, створена в одному самодостатньому файлі `index.html` без використання сторонніх бібліотек або фреймворків (чистий HTML5 + CSS3 + Canvas API + Web Audio API).

---

## 🎮 Як грати

1. Відкрийте файл [`index.html`](file:///c:/Users/twoch/OneDrive/Dokumenty/GitHub/defense/index.html) у будь-якому сучасному веб-браузері (Chrome, Firefox, Edge, Safari тощо).
2. На початковому екрані оберіть карту битви:
   - **🌿 Зелена долина** (Нормальна складність): мальовнича звивиста лісова стежка, ідеальна для збалансованої оборони.
   - **🌋 Лавовий каньйон** (Висока складність): небезпечна розколина серед вулканічних порід із крутими поворотами та мостами через лаву.
3. Оберіть тип вежі в нижній панелі або натисніть гарячі клавіші `1`, `2`, `3`.
4. Натисніть на будь-яку вільну ділянку землі, щоб побудувати вежу.
5. Натисніть на розміщену вежу, щоб відкрити панель її характеристик:
   - **⬆️ Покращити**: збільшує урон, радіус огляду та швидкість атаки (всього 4 рівні з унікальним зовнішнім виглядом для кожного рівня).
   - **💰 Продати**: повертає 70% від загального інвестованого золота.
6. Натисніть кнопку **⏩ SKIP** зверху посередині (або **▶ Почати хвилю** внизу, чи клавіші `Пробіл` / `Enter`), щоб розпочати битву або викликати наступну хвилю завчасно!

---

## ⏩ Кнопка SKIP (Пропустити)

Кнопка **⏩ SKIP** розташована зверху посередині екрана:
- **Між хвилями**: миттєво запускає наступну хвилю.
- **Під час активної хвилі**:
  - Миттєво висаджує всіх ворогів з черги очікування на карту (без очікування затримок).
  - Одразу викликає наступну хвилю з **бонусом +30🪙 золота** за швидкість і сміливість!
- **Чит для тестування**: затиснувши `Ctrl` або `Shift` при кліку на SKIP, поточна хвиля миттєво завершується.
- **Гарячі клавіші**: `Enter` або `N`.

## ⌨️ Керування та клавіші

- `1`, `2`, `3` — швидкий вибір типу вежі для будівництва.
- `Enter` / `N` — кнопка **SKIP** (пропустити очікування / викликати хвилю раніше).
- `Клік / Тач` по землі — побудувати обрану вежу.
- `Клік / Тач` по вежі — відкрити параметри, радіус атаки та кнопки покращення/продажу.
- `U` — покращити обрану вежу.
- `S` — продати обрану вежу.
- `Esc` — зняти виділення з вежі.
- `Пробіл` — запустити хвилю / пауза гри.
- `x1 / x2` — перемикач швидкості гри.
- `🔊 / 🔇` — вмикання/вимикання синтезованих звукових ефектів.
