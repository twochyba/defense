# Generated interface backgrounds

Created with the built-in image_gen tool. Final prompts are recorded below.
Runtime assets are WebP (quality 80): 1600×900 for desktop and 800×450 for screens up to 800px wide.
Backgrounds use CSS cover with a dark overlay. The existing solid colors remain as loading/error fallbacks.
The armory background belongs to the initially hidden units modal. No artwork is drawn by the combat render loop.
Keep the assets directory beside index.html when copying or deploying the game.

## Naval menu

Use case: stylized-concept. Asset type: wide background artwork for the main menu of a military tower defense browser game. Scene: fictional naval defense harbor at blue hour, concrete docks, shipping containers, radar installations, distant destroyer silhouettes, a small coastal defense turret in lower right foreground, restrained amber dock lights reflected in dark water. Style: polished cinematic game environment illustration with realistic materials, cool navy and slate palette, subtle cyan light, crisp silhouettes. Composition: wide landscape 16:9, panoramic harbor arranged toward outer edges, dark calm low-detail central 60 percent left free for readable existing menu text and buttons. Atmospheric but legible, no combat gore, no people closeups, no writing, no logos, no flags, no watermarks, no UI. This is a finished background asset, not a screenshot.

## Armory

Use case: stylized-concept. Asset type: wide atmospheric background for unit equipment selection modal in a military tower defense browser game. Scene: empty fictional military arsenal interior, equipment benches, orderly tool storage, armored vehicle silhouette and a compact reconnaissance drone resting on a bench near the outer edges. Style: polished cinematic game environment illustration with realistic steel, subdued slate navy palette, soft cyan overhead lights and tiny amber accents. Composition: wide landscape 16:9, center 70 percent deliberately dark and low detail for legibility of existing interface cards and text. No people, no writing, no insignia, no logos, no flags, no watermarks, no UI. Finished background asset.
