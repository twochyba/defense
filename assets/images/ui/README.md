# Generated game artwork

Generated with the built-in image_gen tool, one call per asset. No CLI/API fallback. Final files are WebP; portraits are 384×384, mode banners 640×360, terrain 1500×900, road 256×256, prop sprites 128×128 with alpha, button material 768×256.

Portraits, difficulty banners and button material are in this directory. Terrain, road, pine and rock are in `../battlefield/`. The existing naval assets remain in `../naval/`.

The road follows the original exact path; decorative sprite positions match blocked cells. Backgrounds are cached once. Portraits use lazy loading and repeated URLs share the browser cache. Button text is live HTML over generated material.
